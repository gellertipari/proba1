## 🚀 Kezdés

### Előfeltételek
- Node.js >= 14.0
- npm vagy yarn
- Git

### Telepítés

```python
# Repository klónozása
git clone https://github.com/user/proba1.git

print('Helloworld')

# Könyvtárba lépés
cd proba1

# Függőségek telepítése
npm install
```

---

## 💻 Használat

### Alapvető indítás

```bash
npm start
```

### Fejlesztési mód

```bash
npm run dev
```

### Build

```bash
npm run build
```

## 🤝 Hozzájárulás

Szívesen fogadunk pull requesteket! Kövesse az alábbi lépéseket:

1. Fork a projektnek
2. Hozzon létre egy feature branch-et (`git checkout -b feature/AmazingFeature`)
3. Commit az Ön módosításait (`git commit -m 'Add some AmazingFeature'`)
4. Push a branch-hez (`git push origin feature/AmazingFeature`)
5. Nyisson egy Pull Request-et
